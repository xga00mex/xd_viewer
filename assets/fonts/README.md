# Noto Sans TC

Offline fallback: Noto Sans TC, version 2.04, weights 100–900. Converted from
the locally installed `NotoSansTC-VF.ttf` to WOFF2 with fontTools 4.60.1;
glyphs, names and variation axes are retained. The font's embedded license
is SIL Open Font License 1.1. Copyright 2014–2021 Adobe.

Upstream: https://github.com/google/fonts/tree/main/ofl/notosanstc

`OFL.txt` is included in the application notices and in every exported CSS
font declaration, including standalone HTML and SVG files.

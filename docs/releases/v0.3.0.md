# XV 0.3.0 — 發布草案

原始碼版本：0.3.0。日期：2026-10-28。尚未打包、建立版本標籤或發布 Release。

- 產品、視窗、SVG／ICO 圖示與套件改為 XV；預計下載檔名為 `XV-0.3.0-Windows-x64.exe`，啟動檔為 `Start-XV.cmd`。新工作檔使用 `.xv`，仍可讀取 `.xdlocal`。自動工作階段改存於 `%APPDATA%/XV/`，找不到新工作階段時可讀取舊資料。
- 全畫板使用等尺寸卡片與完整等比縮圖，點選卡片進入對應畫板。長畫板不再拉長總覽卡片。
- 左鍵拖曳框選、Shift 點擊切換多選、Shift 框選追加。空白鍵／中鍵拖曳繼續用於捲動。右鍵提供組合、解散群組、匯出素材；組合也支援 Ctrl／⌘+G，解散支援 Ctrl／⌘+Shift+G。
- 群組保存於工作檔，可復原與重做。組合保留相對位置、矩陣、圖層順序及必要的祖先效果容器；完整選取群組後，其後代不會重複加入。含遮罩、元件狀態或共用效果的既有群組不能直接攤平，以免損失外觀，介面會顯示原因。
- 素材匯出加入「移除圖層透明度」，預設不勾選；套用於 SVG、PNG、批次與合併匯出的共用 SVG 來源。只移除圖層／群組 opacity，不修改圖片像素、填色或陰影的 alpha。
- 預覽改由 Blob 文件導覽，避免空 srcdoc 覆蓋目標；資源仍內嵌，互動腳本仍由應用程式資源載入。保留沙箱隔離，新增載入完成訊息及逾時提示。容器尚未取得寬度時不再把畫板縮成零。
- 清除目前原始碼、測試與文件中找到的參考稿文案與樣本細節；加入本機原稿與工作檔忽略規則，以及不輸出原文的本機參考稿掃描工具。回歸案例使用原創示範或合成資料。

驗證方法為 TypeScript、Vitest、Happy DOM 記憶體事件及 Sharp 像素比較。未使用 Windows／瀏覽器 UI 自動化；實際 Chromium 視覺、Canvas PNG 下載與 Windows 發布封裝尚待驗證。參考稿掃描不等於重寫舊 Git 歷史或清除既有 Release。

群組的基本操作參考 [Adobe 的命令介面說明](https://developer.adobe.com/xd/uxp/develop/reference/commands/)；這是本工具支援的操作範圍，未宣稱完整重製編輯器。

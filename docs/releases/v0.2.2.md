# v0.2.2 — 文字修正、滑鼠拖曳與合併素材

版本 0.2.2，2026-10-27。下載：[GitHub Release](https://github.com/xga00mex/xd_viewer/releases/tag/v0.2.2)。

## 改善

- 修正購物車步驟二「差 $100 元即可享免運優惠」的文字重疊。同一行的不同字型／字重片段會接續排列；頁尾等相同格式的文字也一併修正。保留原始換行與明確定位。
- 檢視模式可直接按住滑鼠左鍵拖曳，水平或垂直捲動畫板。單擊仍可選取圖層，Ctrl／⌘／Shift 多選、Alt 測距及空白鍵／中鍵拖曳繼續可用。拖曳結束、取消或視窗失去焦點時會釋放拖曳狀態。
- 多選同一畫板的素材，開啟「匯出素材」並勾選「合併成單一素材」，即可輸出一個 SVG 或 PNG。保留畫板中的相對位置、旋轉、圖層順序、祖先透明度與遮罩，重複選到的群組／子圖層只繪製一次。未勾選時維持個別素材 ZIP 匯出。

## 更新後使用

關閉舊版，執行 `XD-Local-0.2.2-Windows-x64.exe`，**重新開啟原始 `.xd`** 以套用文字解析修正。舊 `.xdlocal` 及自動工作階段保存的是原本的解析結果，不會自動重建。原始 XD 檔不會被修改。

## 驗證

- `npm run check`：61 項測試通過，包含實際文件的 22 個畫板、55 張圖片及免運提示回歸檢查。
- 混合樣式文字與連續文字的 Sharp 像素比對一致；購物車步驟二的原檔渲染區域已檢查。
- 合併 SVG 的像素檢查涵蓋相對座標、旋轉、繪製順序、透明背景、祖先遮罩與群組透明度；來源文件保持不變。
- Happy DOM 檢查左鍵拖曳、單擊／多選、取消／失焦清理，以及勾選合併後輸出單一 SVG 的完整介面事件流程。
- 正式 bundle 使用 `npm run smoke` 檢查；封裝 EXE 以 `npm run smoke:desktop` 進行無視窗執行環境與資源診斷。

驗證使用命令列、Sharp 與記憶體 DOM，未採用 Windows／瀏覽器 UI 自動化。PNG 沿用相同 SVG 來源與既有 Canvas 編碼；未宣稱實際 GUI 或 Canvas 下載的視覺驗收。少數自訂圖片裁切、缺少原稿字型、原始原型連線與動態元件狀態仍有既有相容性限制。

# v0.2.4 驗證紀錄

日期：2026-10-28（Asia/Taipei）。環境：Windows x64、Node.js 24.19.0、Electron 45.0.0。

- 固定背景回歸測試先失敗：商品位置的像素從應有的紅色變成背景灰色。恢復 XD 原始順序後，固定背景、商品及其後的白色購物車像素均正確。HTML 匯出亦檢查原稿固定背景未被強制指定高 z-index。
- 同一份 17 畫板、96 圖片的 XD，以舊版固定圖層排序重現使用者截圖的背景與浮動元件；恢復順序後，畫板頂端的橫幅、商品圖片、價格與導覽重新出現。比較用的原檔渲染圖只存於本機。
- 全畫板 DOM 回歸先失敗：視圖只有 iframe，沒有可直接繪製的畫板。改為主文件 SVG 後，驗證每個畫板的名稱與圖片；另檢查按需載入、離開模式時的 observer 與 DOM 清理。
- 實際 XD 的最大畫板亦經過 Studio → 全畫板 → IntersectionObserver 載入路徑，核對 SVG 的畫板名稱、尺寸及繪圖節點，iframe 為空且隱藏。
- `npm run check`：前端／桌面 TypeScript 與 69 項一般測試通過；7 項本機 XD 測試預設略過。
- 本次 XD 的既有 6 項驗證全部通過：圖片解碼、工作檔往返、畫板座標、全文範圍、所有畫板渲染、全畫板 SVG ZIP 與單頁 HTML。新增的原檔全畫板 DOM 測試另為 1／1 通過。
- `npm run smoke`：正式 bundle 顯示範例畫板與全畫板 SVG，總覽不依賴 iframe；互動預覽產物、編譯後的互動 runtime、原生儲存、關閉前寫入與離線 HTML 檢視器通過。
- `npm run dist:win`、`npm run smoke:desktop`：Windows x64 portable EXE 封裝與無視窗診斷通過，版本為 0.2.4；詳細執行環境見 `desktop-verification.json`。
- `npm run format:check`、`git diff --check`：通過。

遵守全域偏好，未使用 Windows／瀏覽器 UI 自動化。檢查方法為命令列、Sharp、記憶體 DOM 與 Electron 無視窗 API；未宣稱實際 GUI／Canvas PNG 下載驗收。互動預覽仍使用隔離 iframe，既有格式與 PNG 尺寸限制維持。

Release 只含程式、原創離線範例、校驗碼、第三方聲明及驗證紀錄。原始 XD、使用者截圖及私有設計渲染圖不公開。

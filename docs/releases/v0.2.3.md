# v0.2.3 — 缺字、預覽與全畫板輸出

版本 0.2.3，2026-10-28。下載：[GitHub Release](https://github.com/xga00mex/xd_viewer/releases/tag/v0.2.3)。

## 修正與新增

- 修正「加入購物車」、價格等文字缺字：XD 的 rangedStyles 長度未隨文字編輯更新時，保留未涵蓋的字元，維持原始分行、基線與已知樣式。
- 互動預覽改為內嵌頁面與封裝內的獨立腳本，避免 opaque-origin 沙箱依賴 Blob 子資源；保留 iframe 隔離與畫板導覽。
- 新增工具列「全畫板」，在同一頁查看所有完整畫板；匯出用途選「全畫板單頁 HTML」可離線交付。
- 設計素材新增「全部畫板」範圍，逐板輸出 SVG／PNG 並打包 ZIP，不必手動多選。
- 保留 XD 的固定圖層及獨立堆疊，讓手機快捷購物車等浮動面板維持原始背景與透明度；避免巢狀固定圖層重複定位。
- 匯入已儲存的雙狀態點擊 Toggle，包括 interaction GUID 的繼承資料；預覽與 HTML 保留兩種狀態。修正巢狀 Toggle 鍵盤事件重複觸發，並同步多個控制鈕的展開狀態。
- 保留 XD 指定字型；缺少時通知並列於相容性報告，回退內附的 Noto Sans TC。備援字型、100–900 字重與 OFL 授權隨 HTML、SVG 和程式碼輸出保存，全程離線。
- 分開儲存定義與展開圖層的安全上限，讓大量元件狀態的文件可匯入，展開場景仍限制為 50,000 圖層。

## 使用

關閉舊版，執行 `XD-Local-0.2.3-Windows-x64.exe`，**重新開啟原始 `.xd`**。舊 `.xdlocal`／自動工作階段保留舊解析資料，不會自動補回缺字或元件狀態。原始設計不會被修改。

## 驗證與限制

驗證涵蓋 TypeScript、Vitest、正式 bundle 的記憶體 DOM、Sharp 像素與實際 XD 匯入／往返／完整畫板渲染，以及封裝 EXE 的無視窗資源診斷。詳見同頁的 `verification.md` 與 `desktop-verification.json`。

依使用者全域偏好未使用 Windows／瀏覽器 UI 自動化；尚未實際操作 GUI 或驗收 Canvas PNG 下載。雙狀態切換保留狀態內容，不包含 Auto-Animate 補間；多狀態、Hover 狀態、其他原型連線與特殊圖片裁切仍有相容性限制。PNG 的單邊 16,384 px／64 百萬像素上限沿用既有規則，超長畫板請用 SVG。

# v0.2.0 — Windows 桌面版

XD Local 的首個公開下載版本。提供繁體中文三欄 GUI，直接開啟 EXE 即可在本機檢視 XD 設計稿、量測、檢查 CSS、匯出素材與設定互動。

## 下載與使用

1. 在下方 Assets 下載 **XD-Local-0.2.0-Windows-x64.exe**（約 105 MiB）。
2. 雙擊 EXE，使用「開啟檔案」選取 `.xd`，或載入內建範例。
3. 匯出選「HTML 檢視」可產生包含素材、字型與支援互動的單一 HTML；需要切版原始碼時可選 HTML／CSS／JS ZIP。

程式內含執行環境，不需要另外安裝 Node.js、Adobe XD 或啟動 localhost。Windows x64；此版 EXE 尚未使用發行者憑證簽章。

## 功能

- XD 畫板與圖層解析、縮放、選取、尺寸與間距量測。
- CSS 屬性檢查與複製、本機字型載入。
- PNG／SVG 單獨與批次匯出，可移除向量矩形與遮罩圓角。
- Click、Hover、Scroll、Sticky、Fixed、Animation 設定與即時預覽。
- XD 風格 HTML 檢視器：畫板導覽、返回、縮放、全螢幕、熱區提示及重播。
- 可維護的 HTML／CSS／原生 JS 匯出，以及 Flex／Grid 響應式設定。
- 原生檔案對話框、本機工作階段保存與 `.xdlocal` 工作檔。

## 驗證與相容性

TypeScript 檢查、41 項測試、正式 bundle 的記憶體 DOM 驗證及封裝 EXE 的無視窗資源診斷均已通過。尚未執行實際 GUI 的自動化視覺驗收。

目前支援部分 XD／AGC 特性，匯入時會列出相容性提醒。XD 原有 prototype 連線、Auto-Animate、元件實例覆寫及部分模糊／特殊效果尚未完整支援；HTML 檢視保留目前已支援的外觀與本工具設定的互動。文字還原精度仍取決於原稿字型是否可用。

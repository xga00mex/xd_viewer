# v0.2.1 — 圖片與多畫板相容性修正

版本 0.2.1，2026-10-27。下載：[GitHub Release](https://github.com/xga00mex/xv/releases/tag/v0.2.1)。

## 修正

- 非原點畫板的子圖層原先留在整份文件的座標，可能整板空白。現在於畫板邊界使用 `meta.ux.localTransform`，缺少時扣除畫板偏移；不改動巢狀座標。
- 畫板 metadata 與 manifest 逐欄合併，保留各自提供的尺寸、位置與捲動視窗。
- 圖片同時支援 UID、封裝內相對路徑、Windows 檔名與 manifest 資源 ID。UID 無效時可退回已存在的封裝內圖片；不同目錄的同名圖片不再互相覆蓋，有歧義的簡稱不會任意選圖。
- 支援兩種 symbols 儲存位置與 `syncSourceGuid`，還原元件內圖片、向量和文字及已儲存的實例覆寫；保留循環與資源上限檢查。
- 布林圖形使用已儲存的結果路徑，不重複繪製運算元；讀取內嵌 `gradientResources`，避免漸層消失。
- 尚未還原的自訂圖片裁切會提供圖層提醒。

## 驗證

- `npm run check`：52 項測試通過；本機參考文件完成圖片解碼與畫板渲染檢查。
- 四畫板合成案例涵蓋正負偏移、跨畫板共用圖片、失效 UID、Windows 路徑、相對路徑、同名資源與 manifest 欄位補足。直接比較圖片像素，並以 Happy DOM 反覆切換畫板，檢查場景、圖片與捲動重設。
- 工作檔往返、所有畫板的素材連結及代表畫板的單檔 HTML 內嵌檢查通過。
- `npm run smoke`：正式 bundle 與單檔 HTML 的記憶體 DOM 檢查通過。
- Windows 可攜式程式由 `npm run dist:win` 產生；封裝後以 `npm run smoke:desktop` 驗證執行環境與資源，結果見 `release/desktop-verification.json`。

使用命令列、Sharp 與記憶體 DOM，未使用 Windows／瀏覽器 UI 自動化。上述結果不等同所有 XD 格式或實際 GUI 的視覺驗收；未取得的其他問題檔案無法逐檔確認。

## 使用

關閉舊版，再執行 `release/XD-Local-0.2.1-Windows-x64.exe` 或 `Start-XD-Local.cmd`，重新開啟原始 `.xd`。舊工作檔及自動工作階段保留舊版解析結果，不會因更新程式自動重建。

自訂圖片裁切仍以置中填滿近似；缺少原稿字型仍可能改變字寬。動態元件狀態與原始原型連線尚未匯入。

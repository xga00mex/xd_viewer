# v0.2.4 — 一頁式商品遮蓋與全畫板空白修正

版本 0.2.4，2026-10-28。下載：[GitHub Release](https://github.com/xga00mex/xd_viewer/releases/tag/v0.2.4)。

## 修正

- 一頁式購物只剩背景與浮動購物車的原因，是固定背景被錯誤移到前景。SVG 恢復 XD 原始圖層順序，HTML 匯出不再替所有原稿固定圖層強制指定高 z-index。固定背景、商品圖、橫幅、文字與浮動控制項各自保持原稿的前後關係。
- 工作台「全畫板」改為直接顯示畫板 SVG，不透過 iframe 或互動頁面載入。保留完整畫板比例與標題，依捲動提前載入，離開模式時釋放 observer 與畫板 DOM。
- 保留全畫板 SVG／PNG ZIP、離線單頁 HTML、原稿字型與 Noto Sans TC 備援、雙狀態 Toggle，以及既有缺字修正。

## 使用

關閉舊程式後，執行 `XD-Local-0.2.4-Windows-x64.exe`。此問題是顯示順序造成，既有 `.xdlocal` 可繼續使用；原始 XD 不會被修改。

## 驗證

以同一份 17 畫板、96 圖片的 XD 重現舊版僅剩背景與浮動元件的畫面；修正後的原檔渲染恢復橫幅、商品圖片與價格。合成像素測試涵蓋固定背景、商品與購物車的原始繪製順序。DOM 測試驗證全畫板實際包含圖像、捲動載入與離開清理；正式 bundle 亦檢查總覽直接顯示 SVG。完整結果見 `verification.md` 與 `desktop-verification.json`。

依全域偏好，驗證使用命令列、Sharp、記憶體 DOM 及 Electron 無視窗 API；未執行 Windows／瀏覽器 UI 自動化或實際 GUI 驗收。互動預覽仍使用隔離 iframe，其完整視覺驗收不在本次範圍。PNG 尺寸上限、特殊圖片裁切、多狀態／Hover 與 Auto-Animate 等既有限制維持不變。
